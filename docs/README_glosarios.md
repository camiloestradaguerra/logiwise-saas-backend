# Glosario de Términos Logísticos (Latam)

Este archivo contiene definiciones ampliadas y ejemplos de uso de términos logísticos clave, con foco en operaciones internacionales y documentación. Es ideal para usuarios que buscan comprender los documentos, impuestos y actores principales en la logística de Latinoamérica.

Incluye:
- Documentos de transporte (BL, AWB, Factura Comercial)
- Conceptos fiscales (IVA, Retención)
- Roles (Carrier, Cliente)
- Definiciones de carga (FCL, LCL, Peso Volumétrico)
- Otros términos prácticos

Ubicación: `nuevaflo_core/docs/glosario.md`

---

# Glosario Logístico General

El archivo `docs/glosario_logistico.md` contiene un glosario más orientado a términos operativos, procesos y siglas internacionales, útil para equipos de operaciones, ventas y clientes que requieren una visión global de la cadena logística.

Incluye:
- Siglas y abreviaturas (ETA, ETD, FCL, LCL, CBM)
- Procesos (Booking, Tracking, Demora, Detención)
- Conceptos de aduana y seguros
- Incoterms y reglas internacionales

Ubicación: `docs/glosario_logistico.md`

---

**Recomendación:**
- Usa ambos glosarios como referencia complementaria.
- Si tienes dudas sobre un documento, impuesto o rol, consulta primero `nuevaflo_core/docs/glosario.md`.
- Si buscas siglas, procesos o términos de seguimiento y transporte, consulta `docs/glosario_logistico.md`.
